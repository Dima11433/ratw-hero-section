# Ratw — Responsive Hero Section

A polished, responsive Hero Section built with a single HTML file, Tailwind CSS (via CDN), Google Fonts, and Vanilla JavaScript.

## Features
- **Cinematic Background Video:** Looping HD video with an elegant overlay.
- **Sequential Staggered Animations:** Smooth `fadeInUp` keyframe transitions across background, header, headline, subheadline, and CTA over ~4 seconds.
- **Custom Typography:** Google Fonts `Inter` paired with italicized `Playfair Display`.
- **Fully Responsive:** Fluid desktop navigation + custom animated mobile menu (hamburger to close swap).
